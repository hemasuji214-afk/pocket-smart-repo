POCKETSMART AI - VS CODE SETUP

1. Extract this ZIP.
2. Open the PocketSmart_AI folder in VS Code.
3. Open Terminal.
4. Run: python -m venv venv
5. Windows: venv\Scripts\activate
   macOS/Linux: source venv/bin/activate
6. Run: pip install -r requirements.txt
7. Run: python app.py
8. Open the local address shown in the terminal (normally http://127.0.0.1:5000/).

The app includes a budget dashboard, expense tracker and simple recommendation planner.
